# FincAi

Aplicação full stack de inteligência financeira para gestão, previsões e recomendações de orçamento pessoal.

## Descrição

O FincAi é um projeto pensado para ajudar pessoas a organizar suas finanças, controlar gastos, acompanhar receitas e receber recomendações de equilíbrio financeiro com base em dados e regras de negócio aplicadas ao contexto pessoal.

## Objetivo

Criar uma solução prática para gestão financeira pessoal, combinando front-end, back-end e lógica de análise para melhorar a tomada de decisão sobre orçamento e despesas.

## Stack

- PHP
- Laravel
- HTML
- CSS
- JavaScript
- Banco de dados relacional
- Git / GitHub

## Funcionalidades

- Cadastro de receitas e despesas
- Organização por categorias
- Visualização geral do orçamento
- Sugestões de previsão e análise financeira
- Estrutura de aplicação full stack
- Organização do código e manutenção do projeto

## Como executar

1. Clone o projeto
2. Configure as variáveis de ambiente
3. Instale as dependências com Composer
4. Execute as migrations
5. Inicie o servidor local

## Estrutura do projeto

- Front-end: interfaces e interações do usuário
- Back-end: lógica de negócio e APIs
- Banco de dados: persistência de dados financeiros
- Organização: estrutura modular para facilitar manutenção

## Status

Projeto em desenvolvimento com foco em evolução funcional e melhoria da experiência do usuário.
